연결 상태

로컬 서버에 연결되지 않았어요. 지금은 데모 화면이에요.

npm install     # 처음 한 번 (스프라이트 자동 다운로드)
npm run hooks   # 처음 한 번 (Claude Code 연결)
npm start       # 매번 → http://127.0.0.1:4321
npm run doctor  # 안 될 때 진단
테스트 이벤트 — 가짜 이벤트로 화면만 움직여 봐요 (토큰 사용 없음)
