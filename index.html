! 트레이너가 부르고 있어요
포켓몬이나 트레이너를 탭해 보세요.

의뢰 보내기 현재 사무실 · 세션 1

버튼은 훅 이벤트(PreToolUse → PostToolUse)를 흉내 내요. 해당 방으로 포켓몬이 걸어가 일해요. 연달아 누르면 여럿이 동시에 일해요.

직접 PNG 넣기 (서버 없이)

파일 이름이 번호.png 이거나 역할 이름(read.png, trainer.png)이면 자동으로 짝지어져요.

스프라이트는 이 브라우저에만 저장돼요. 녹화해서 공개하거나 배포하면 저작권 문제가 생길 수 있으니 개인용으로 쓰세요.

로컬 서버에 연결되지 않았어요. 지금은 데모 사무실 2곳이 돌아가요.

npm install   # 스프라이트 자동 다운로드
npm start     # http://127.0.0.1:4321

그다음 ~/.claude/settings.json에 훅을 넣으면(README) 실제 Claude Code를 따라 움직여요. 프로젝트 폴더마다 사무실(상단 탭)이, 세션마다 트레이너가 생겨요.

기본 몬스터·트레이너·사무실 그림은 이 프로젝트용 오리지널 픽셀 아트입니다. 포켓몬 스프라이트는 내려받은 앱에서 사용자가 직접 받아 이 PC에서만 씁니다.
